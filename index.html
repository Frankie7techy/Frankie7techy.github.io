// 01. Who am I
About Me

I'm Frank Ngaruiya, a security engineer and bug bounty hunter based in Kenya. I break web applications for a living and build tools that help others do the same.

My work focuses on finding real vulnerabilities in production systems — SQL injection, XSS, IDOR, SSRF, XXE, command injection — the bugs that actually matter. I report them through responsible disclosure programs and publish writeups so the community learns from every finding.

When I'm not hunting bugs, I'm building security tools, grinding CTF challenges on PortSwigger Web Security Academy, or contributing to open source. I believe in transparent, ethical security research — every vulnerability I find gets reported to the affected company first.

Philosophy: Find it. Report it. Document it. Share it.

// Disclosure Policy

All vulnerabilities are reported directly to the affected organization through their responsible disclosure program before any public disclosure. I follow coordinated disclosure timelines and never publish exploit details until a fix is deployed. Every finding is documented with proof-of-concept, impact analysis, and remediation steps.
